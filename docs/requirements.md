# 需求清单

> 随对话持续更新。状态标记：✅ 已确认 / 🟡 讨论中 / ⬜ 待补充 / ❌ 已否决
> 最近更新：2026-11-02（第 5 次归档）

## 一、项目定位

个人专属内容平台，由用户本人主导设计，与多个 AI 协作开发。

**单一项目**，包含三个功能模块 + 用户体系，统一部署在一台自建服务器上（见 D-006）。

| 模块 | 状态 | 说明 |
|---|---|---|
| 访客端 | 🟡 需求收集中 | 对外展示，是网站的「门面」 |
| 管理后台 | 🟡 需求收集中 | 站主自用，功能庞大 |
| 文件系统 | ⬜ 暂缓开发 | 网页版资源管理器 |
| 用户与权限 | 🟡 设计中 | GitHub / 邮箱登录 |

---

## 二、设计原则

> **该好看的地方做到极致，该干活的地方干净利落。**

| 区域 | 视觉强度 |
|---|---|
| 访客端博客 | ✨ 特别漂亮，是门面 |
| 管理后台 | ✨ 也漂亮，站主每天都要看 |
| 文件系统等工具页 | ⚪ 极简，功能优先，不加装饰 |

## 三、模块一：访客端

### 导航结构

```
首页
├── 友链
├── 关于我
│    ├── 个人简介
│    └── 我的家（老婆孩子等生活记录）
├── 阅读与思考
├── 学习笔记
└── 资源 → 进入文件系统
```

### 首页

| 编号 | 需求 | 状态 |
|---|---|---|
| F-01 | 未登录显示「Hi，欢迎来到我的博客」，**文案可在后台修改** | ✅ |
| F-02 | 已登录显示「Hi，别来无恙！」 | ✅ |
| F-03 | 问候语下方为** 打字 效果文字显示 ** | ✅ |

### 内容结构

| 编号 | 需求 | 状态 |
|---|---|---|
| F-04 | 「阅读与思考」「学习笔记」为**两个文章分类，一篇文章归属其一** | ✅ |
| F-05 | 「个人简介」「我的家」为**独立页面**，不是文章 | ✅ |
| F-06 | 「我的家」为**可不断更新的图文页** | ✅ |
| F-07 | 「友链」为**结构化表**（名字/网址/头像/简介），后台可增删改查 | ✅ |
| F-08 | **中英双语**：每篇文章可有中文版与英文版 | ✅ |

### 交互与体验

| 编号 | 需求 | 状态 |
|---|---|---|
| F-09 | **SPA 体验**：站内切换不刷新整页，只替换内容区 | ✅ |
| F-10 | 切换时地址栏 URL 同步变更，支持分享与前进/后退 | ✅ |
| F-11 | 深色 / 浅色主题切换 | 🟡 借鉴自参考站，待确认 |
| F-12 | RSS 订阅 | 🟡 借鉴自参考站，待确认 |
| F-13 | **未翻译文章行为**：英文读者访问仅有中文版的文章时，**直接显示中文原文**（不提示、不隐藏） | ✅ |

### 参考站借鉴元素

参考 [马健宇个人站](https://www.math.univ-toulouse.fr/~jma/zh/)（技术栈为 VitePress）：

- 时间倒序的文章流，日期在左、标题加摘要
- 标签聚合页
- 多语言切换
- 深浅色主题
- RSS 订阅
- 顶部挂个人简历 / GitHub 入口
- 极简排版，减少装饰

## 五、模块三：文件系统

> **定位澄清**：本模块是「资源库」，不是「个人网盘」。用户明确表示私人文件不会上传。

| 编号 | 需求 | 状态 |
|---|---|---|
| S-01 | 形态为网页版资源管理器（目录树 + 文件列表） | ✅ |
| S-02 | 作为**独立模块**存在，而非独立项目 | ✅ |
| S-03 | 当前暂缓开发 | ✅ |
| S-04 | 上传文件时在数据库登记记录，状态初始为「临时」 | ✅ |
| S-05 | 保存文章时，将正文引用到的文件标记为「已使用」 | ✅ |
| S-06 | 定时清理：长期未引用的临时文件移入回收站，不直接删除 | ✅ |
| S-07 | 维护文件与文章的引用关系，支持反查 | ✅ |
| S-08 | **访客只有浏览与下载（拉取）权限，不能上传** | ✅ |
| S-09 | **不做权限隔离**：所有文件对登录用户可见（因不含私人文件） | ✅ |
| S-10 | 站主拥有全部操作权限：上传、重命名、移动、删除 | ✅ |
| S-11 | 界面从简，功能优先（见设计原则） | ✅ |

**远期规划**：用户计划自建 NAS 类个人云平台。

## 六、模块四：用户与权限

| 编号 | 需求 | 状态 |
|---|---|---|
| U-01 | **GitHub OAuth 登录**，无需审核，登录即通过 | ✅ |
| U-02 | **邮箱 + 密码**登录 | ✅ |

| U-06 | 访客登录后只能查看、下载资源，**无任何写入权限** | ✅ |
| U-07 | 支持中英双语界面 | ✅ |

## 七、协作约束

| 编号 | 约束 | 状态 |
|---|---|---|
| C-01 | 用户主导节奏，一步一停，AI 不擅自推进 | ✅ |
| C-02 | 用户 AI 额度有限，尽量减少来回确认 | ✅ |
| C-03 | 多个 AI 共同开发同一仓库，需识别他人新增的文件 | ✅ |
| C-04 | 所有需求、疑问、架构讨论必须落盘到本仓库 | ✅ |
| C-05 | 用户说「归档」时，按 AGENTS.md 归档协议执行 | ✅ |
