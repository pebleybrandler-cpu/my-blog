# 需求清单

> 本文档随对话持续更新。状态标记：✅ 已确认 / 🟡 讨论中 / ⬜ 待补充 / ❌ 已否决

## 一、项目定位

个人专属内容平台，由用户本人主导设计，与多个 AI 协作开发。

整体拆分为**两个独立项目**，分别开发、分别部署、互不耦合：

| 项目 | 状态 | 说明 |
|---|---|---|
| 个人博客 | 🟡 需求收集中 | 当前主攻方向 |
| 个人文件系统（网页版资源管理器） | ⬜ 暂缓 | 博客完成后再启动，单独仓库、单独部署 |

---

## 二、模块一：访客端（对外展示）

| 编号 | 需求 | 状态 |
|---|---|---|
| F-01 | 供外部访客访问，无需登录 | ✅ |
| F-02 | 访客可查看文章等公开内容 | ✅ |

**待补充**：
- ⬜ 首页布局 / 导航结构
- ⬜ 文章列表形式（时间流 / 分类 / 标签 / 搜索）
- ⬜ 文章详情页元素（目录、评论、分享、相关推荐）
- ⬜ 是否需要评论、订阅、留言
- ⬜ 移动端适配要求

---

## 三、模块二：管理后台（站主自用）

| 编号 | 需求 | 状态 |
|---|---|---|
| B-01 | 站主专属后台，规模庞大、功能复杂 | ✅ |
| B-02 | 用户将通过手绘示意图描述界面 | ✅ |

**待补充**：
- ⬜ 手绘示意图（用户绘制中）
- ⬜ 登录与鉴权方式
- ⬜ 内容管理范围（文章 / 分类 / 标签 / 媒体 / 评论 / 用户）
- ⬜ 是否需要数据统计、SEO 管理、发布流程

---

## 四、模块三：个人文件系统（暂缓）

| 编号 | 需求 | 状态 |
|---|---|---|
| S-01 | 形态为网页版资源管理器（类 Google Drive / 阿里云盘） | ✅ |
| S-02 | 作为独立项目存在，不并入博客 | ✅ |
| S-03 | 当前暂不开发 | ✅ |

**远期规划**：用户计划自建 NAS 类个人云平台。

---

## 五、协作约束

| 编号 | 约束 | 状态 |
|---|---|---|
| C-01 | 用户主导节奏，一步一停，AI 不擅自推进 | ✅ |
| C-02 | 用户 AI 额度有限，尽量减少来回确认 | ✅ |
| C-03 | 多个 AI 共同开发同一仓库，需识别他人新增的文件 | ✅ |
| C-04 | 所有需求、疑问、架构讨论必须落盘到本仓库，不能只存在于对话中 | ✅ |
