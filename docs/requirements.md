# 需求清单

> 随对话持续更新。状态标记：✅ 已确认 / 🟡 讨论中 / ⬜ 待补充 / ❌ 已否决
> 最近更新：2026-11-02（第 2 次归档）

## 一、项目定位

个人专属内容平台，由用户本人主导设计，与多个 AI 协作开发。

**单一项目**，内含三个模块，统一部署在一台自建服务器上（见 D-006）。

| 模块 | 状态 | 说明 |
|---|---|---|
| 访客端 | 🟡 需求收集中 | 对外展示 |
| 管理后台 | 🟡 需求收集中 | 站主自用，功能庞大 |
| 文件系统 | ⬜ 暂缓开发 | 网页版资源管理器 |

---

## 二、模块一：访客端

| 编号 | 需求 | 状态 |
|---|---|---|
| F-01 | 供外部访客访问，无需登录 | ✅ |
| F-02 | 访客可查看文章等公开内容 | ✅ |
| F-03 | **SPA 体验**：站内切换不刷新整页，只替换内容区 | ✅ |
| F-04 | 切换时**地址栏 URL 同步变更**，支持分享与前进/后退 | ✅ |
| F-05 | 切换过程中显示加载状态 | 🟡 若预取够快可能不需要，待定 |

**待补充**：
- ⬜ 首页布局 / 导航结构
- ⬜ 文章列表形式（时间流 / 分类 / 标签 / 搜索）
- ⬜ 文章详情页元素（目录、评论、分享、相关推荐）
- ⬜ 是否需要评论、订阅、留言
- ⬜ 移动端适配要求

---

## 三、模块二：管理后台

| 编号 | 需求 | 状态 |
|---|---|---|
| B-01 | 站主专属后台，规模庞大、功能复杂 | ✅ |
| B-02 | 用户将通过手绘示意图描述界面 | ✅ |
| B-03 | 文章编辑器：上传图片时自动传至 OSS 并在正文插入 URL | ✅ |
| B-04 | 媒体库：查看已上传的全部文件 | ✅ |
| B-05 | 媒体库：显示某个文件**被哪些文章引用** | ✅ |
| B-06 | 媒体库：删除文件前弹出关联文章提示，标题可点击跳转 | ✅ |
| B-07 | 媒体库：被引用的文件是否允许强制删除 | ⬜ 待用户决定（Q-10） |

**待补充**：
- ⬜ 手绘示意图（用户绘制中）
- ⬜ 登录与鉴权方式
- ⬜ 内容管理范围（文章 / 分类 / 标签 / 媒体 / 评论 / 用户）
- ⬜ 是否需要数据统计、SEO 管理、发布流程

---

## 四、模块三：文件系统

> 命名约定：用户暂定称其为「文件系统」（见 D-012）

| 编号 | 需求 | 状态 |
|---|---|---|
| S-01 | 形态为网页版资源管理器（类 Google Drive / 阿里云盘） | ✅ |
| S-02 | 作为**独立模块**存在，而非独立项目（见 D-006） | ✅ |
| S-03 | 当前暂缓开发 | ✅ |
| S-04 | 上传文件时在数据库登记记录，状态初始为「临时」 | ✅ |
| S-05 | 保存文章时，将正文中引用到的文件标记为「已使用」 | ✅ |
| S-06 | 定时清理：长期未被引用的临时文件移入回收站，不直接删除 | ✅ |
| S-07 | 维护文件与文章的引用关系，支持反查（见 D-011、D-012） | ✅ |

**远期规划**：用户计划自建 NAS 类个人云平台。

## 五、协作约束

| 编号 | 约束 | 状态 |
|---|---|---|
| C-01 | 用户主导节奏，一步一停，AI 不擅自推进 | ✅ |
| C-02 | 用户 AI 额度有限，尽量减少来回确认 | ✅ |
| C-03 | 多个 AI 共同开发同一仓库，需识别他人新增的文件 | ✅ |
| C-04 | 所有需求、疑问、架构讨论必须落盘到本仓库 | ✅ |
| C-05 | 用户说「归档」时，按 AGENTS.md 归档协议执行 | ✅ |
